# PokéSurvivor Releases

PokéSurvivor 的公開 Windows 發行檔與自動更新資訊。

Public Windows releases and updater manifests for PokéSurvivor.

## 下載 / Download

請從右側的 **Releases** 下載標示為 `full` 的完整版本。遊戲內附的 Launcher 之後會從同一個 Release 頻道檢查更新。

Download the `full` package from **Releases**. The bundled Launcher checks this same release channel for future updates.
